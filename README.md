# excel2word

Программа берёт значения из Excel и подставляет их вместо плейсхолдеров вида
`{дата_начала}` в Word-шаблоне, создавая по одному .docx на каждую строку.

## Формат Excel

- Первая строка — названия плейсхолдеров **без** `{ }`, например:

  | дата_начала | фио           | должность   |
  |-------------|---------------|-------------|
  | 01.01.2026  | Иванов И.И.   | Менеджер    |
  | 05.01.2026  | Петров П.П.   | Инженер     |

- Заголовок `дата_начала` соответствует плейсхолдеру `{дата_начала}` в Word.
- Каждая следующая строка = один сгенерированный документ.
- Названия файлов результата берутся из первого столбца (если пусто —
  `document_001.docx`, `document_002.docx`, ...).

## Формат Word

Просто впишите в текст `{имя_плейсхолдера}` там, где нужна подстановка —
как обычный текст, форматирование сохранится.

## Как это работает при использовании

1. Скомпилированный бинарник кладётся в папку, где лежат ровно один `.xlsx`
   и ровно один `.docx` (шаблон).
2. Бинарник запускается (двойной клик или из терминала).
3. Результаты появляются в подпапке `output/`.

## Сборка проекта

### 1. Установка Go
https://go.dev/dl/

### 2. Установка зависимостей

```bash
go mod tidy
```

### 3. Сборка под текущую платформу

```bash
go build -o excel2word main.go
```

### 4. Кросс-компиляция

```bash
# Windows (64-бит)
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -o dist/excel2word_windows_amd64.exe main.go

# macOS Intel
GOOS=darwin GOARCH=amd64 CGO_ENABLED=0 go build -o dist/excel2word_macos_amd64 main.go

# macOS Apple Silicon (M1/M2/M3/M4)
GOOS=darwin GOARCH=arm64 CGO_ENABLED=0 go build -o dist/excel2word_macos_arm64 main.go
```
